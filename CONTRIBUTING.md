# Contributing

Thanks for looking at Keephaven.

Issues are welcome: bugs, questions, and hardware reports. "It works on my Pi 5 4GB" or "it doesn't boot from my USB drive" helps a lot, since only the Pi 5 8GB on NVMe has been tested.

Pull requests are welcome too. Before one can be merged, you'll need to agree to the Contributor License Agreement in CLA.md. You keep the copyright in your work, and Keephaven LLC gets the right to use it, including under commercial licenses. The first time you open a pull request, a bot asks you to agree by posting this comment:

    I have read the CLA Document and I hereby sign the CLA

If any code in your pull request isn't yours, say so in the description: where it came from and its license, or, for output from an AI coding tool, which tool (section 7 of the agreement).
