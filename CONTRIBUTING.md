# Contributing

Thanks for looking at Keephaven.

Issues are welcome: bugs, questions, and hardware reports. "It works on my Pi 5 4GB" or "it doesn't boot from my USB drive" helps a lot, since only the Pi 5 8GB on NVMe has been tested.

Pull requests aren't being merged yet, until a contributor agreement is in place. In the meantime, open an issue with the fix or the idea.
